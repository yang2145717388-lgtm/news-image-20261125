A program that draws a newspaper front page summing up the world news of Wednesday, 25 November 2026: Shenzhou-24's launch carrying the first Pakistani astronaut to China's Tiangong station, Australia's October CPI jump to 4.9%, the US Section 301 tariff findings and the PCE and GDP data due today, the Nvidia bounce fading, and the Bank of England chief facing MPs — plus the day's briefs.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024, deterministic) to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when set. Requires Python 3.13 and Pillow 10.2.0; standard library only, no network.
